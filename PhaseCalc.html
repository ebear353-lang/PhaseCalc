cos φ (коэффициент мощности)
Показывает, насколько эффективно прибор использует электроэнергию. Часть мощности уходит в «реактивную» составляющую и не выполняет полезную работу, но всё равно нагружает провода. Чем ниже cos φ — тем больше ток при той же мощности.
  • Лампы накаливания, галоген → cos φ = 1.0
  • LED-приборы с качественным блоком питания (PFC) → 0.9–0.95
  • Дешёвые LED, строб, блиндер с импульсными БП без PFC → 0.5–0.7
  • Если не знаете точно — ставьте 1.0, но с запасом по раздаче
Пример: прибор 1000 Вт при cos φ = 1.0 даёт ток 4.3 А, а при cos φ = 0.6 — уже 7.2 А при том же напряжении.
Одновременность
Доля приборов, которые реально включены одновременно. В световом оборудовании редко бывает так, что ВСЕ приборы горят на полной мощности в один момент.
  • 1.0 — все приборы включены одновременно
  • 0.8 — типичная оценка для шоу, где идёт динамика
  • 0.7 — если уверены, что часть приборов работает в паузах
Пример: 10 приборов по 1000 Вт, одновременность 0.8 → расчёт идёт по 8000 Вт, а не по 10000 Вт. Для ответственных мероприятий всегда ставьте 1.0 или 0.9.
Максимальный ток на фазу
Это предельный ток, который выдерживает автомат или разъём (CEE) на каждой фазе.
  • Автомат C16 / CEE 16A → 16 А (≈ 3.7 кВт при 230 В)
  • Автомат C32 / CEE 32A → 32 А (≈ 7.4 кВт)
  • Автомат C63 / CEE 63A → 63 А (≈ 14.5 кВт)
  • CEE 125A → 125 А (≈ 28.7 кВт)
Пример: на фазе 5 кВт → ток = 5000 / 230 = 21.7 А. CEE 16A не подойдёт.
Как это всё работает вместе
I = (P_фазы × Одновременность) / (U_фазное × cos φ)

Пример: P_фазы = 5000 Вт, одновременность = 0.9, U = 230 В, cos φ = 0.9.
I = (5000 × 0.9) / (230 × 0.9) = 4500 / 207 = 21.7 А.
💡 Простой совет
  • cos φ — 1.0 для ламп накаливания / галогена; 0.9 для LED с PFC; 0.7 для дешёвых LED.
  • Одновременность — 1.0 для ответственной работы; 0.9 для динамичного шоу.
  • Макс. ток на фазу — по номиналу автомата или разъёма (16, 32, 63, 125 А).
